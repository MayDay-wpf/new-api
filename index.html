Capabilities

编码能力与扩展

核心是一条编码循环：读代码、改文件、执行命令、查看诊断、验证结果。终端、检索与 Git 都在循环之内，技能与子代理按需接入。

01 / Coding Loop

编码循环

你描述任务，Agent 自己读代码、定位改动点、写文件、跑命令、看诊断，直到结果被验证——中间不用你搬运上下文。

02 / Codebase

代码库检索与诊断

先检索项目再动手：代码库索引帮它找到真正相关的位置，LSP 诊断让类型与编译错误当场暴露。

03 / Terminal

集成终端

真实 PTY 终端，多标签、工作目录跟随项目。Agent 在这里跑构建和测试，把输出接进下一轮推理。

04 / Git

Git 面板与改动审阅

状态、暂存、提交、分支与差异一屏可见，每处改动都能审阅、授权和回滚；提交前你说了算。

05 / SSH

SSH 远程工作区

把远程主机挂成工作区，文件浏览、终端与 Agent 会话都跑在远端上下文里，本地只留一个窗口。

06 / Browser

内置浏览器

Agent 可以打开页面、抓取内容、按步骤操作界面，再把结果带回对话——验证 Web 改动不用你截图复述。

Security

安全与体验

工具授权与隐私脱敏决定 Agent 能做什么、能看到什么；应用锁默认关闭，只遮盖界面而不加密磁盘数据。

  • 工具授权决定 Agent 能做什么
  • 隐私脱敏决定 Agent 能看到什么
  • 应用锁遮盖界面，PIN 仅存加盐哈希
  • 检查点与回滚，改动随时可退
  • 手机远控，继续当前会话
  • 用量与日志，每次工具调用都有记录
